# 红色剧本杀结构模板（玩家本 / DM 本 / 卡牌 / 物料标准骨架）

> 本模板从两套已验证的红色剧本杀完整案例提炼（出处从略），作为创作时生成剧本的标准骨架与自检清单。方括号【】内为占位符，生成时替换；带 ★ 的为验证过的强约束。

## 一、总体规格

| 项 | 标准 |
|---|---|
| 人数 | 6 人本（1~2 名隐藏身份者可变） |
| 幕数 | 三幕结构：第一幕机制热身+攒资源、第二幕核心推理、第三幕搜证+终局谈判/投票；跨幕资源（货币/积分/羁绊）必须贯通 ★ |
| 阵营 | 至少一条"对抗线"（阵营对抗 / 隐藏身份对抗 / 个人任务对抗三选一或多选组合）★ |
| 时长 | 全程约 3.5~4.5 小时；DM 手册为每环节标注建议时长（如 10/15/20min）并配控时提醒话术 ★ |
| 视角 | 玩家角色与推理对象可分离（玩家扮演调查者，推理对象是 NPC）；或玩家即当事人（个人任务线） |
| 史实处理 | 真实历史做背景锚点，虚构案件承载玩法；史实与虚构必须在 DM 手册中显式标注边界（见 DM 本骨架第 8 条）★ |

## 二、玩家本标准骨架

按页组织，每页末尾固定一行：`——未得到主持人指令，不可翻页——` ★

```
封面页：剧本名 + 【角色名】+ 身份 tag（如 #隐藏穿越者 #关键见证者）★
第一幕
  ├─ 故事背景（该幕真实历史锚点 + 本幕剧情任务，150~300 字）
  ├─ 角色设定（第二人称"你是XX"：身份、性格、动机、与关键人物关系）
  ├─ 游戏机制说明（本幕资源规则：货币/积分/羁绊/暴露值等的获取与用途）★
  ├─ 个人技能（2~3 个，每条：名称+触发条件+效果+使用次数限制）★
  ├─ 持有物品/信物（名称+效果+"贯通全本，谨慎使用"提示）★
  ├─ 注意事项（仅限本人可见的秘密、禁止事项、暴露/失败惩罚阈值）
  ├─ 每个游戏环节：规则要点 → 结束条件与计分 → 【你的任务】主线任务+支线任务（1~2 条，可保密）★
  └─ 环节专属材料页（报纸/照片/棋盘格说明等）
第二幕
  ├─ 故事背景（新时间线，承上启下）
  ├─ 角色设定更新（"故事发生时你正在……"式场景化引入）
  ├─ NPC 列表（如有推理对象：每个 NPC = 身份+年龄+可疑原因 3~5 条）
  ├─ 任务设置（主线任务+支线任务）
  └─ （循环结构时）按周/轮组织的固定版式：背景一段 → 三选一行动项 → 交易/提醒
第三幕
  ├─ 故事背景 + 议题/终局任务（对抗本为双议题；共同目标本为团队目标）
  ├─ 个人技能重申与新增技能
  ├─ 货币消费规则表（进入各搜证点的价格、小道消息价格、兑换规则）★
  ├─ 搜证地图/点位表
  └─ 终局行动提示（第二人称行动引导，唤醒/抉择式文案）
附录：真相页（全员真相公布，翻页限制最严）
```

**视角限定写法**：全程第二人称"你"；只写本角色可知信息（白名单式，如"某某、某某是可以完全信任的战友"）；他人秘密一律不写；需要信息差时用"你了解他们的大致家境与性格，可作为推理参考"这类模糊表述；真相页单独成节并延迟发放。

## 三、DM 本标准骨架

```
0. 排版规范说明（生成时保留）：
   黄色背景=需播放的音频；黑字=基本框架；红字=DM 注意事项；
   蓝字=DM 需要说的话；绿色=时间节点标记；加粗=需重读/特别注意 ★
1. 类型介绍：人数、阵营构成、角色定位一览表、难度与 DM 经验要求（"切勿盲开"提示）
2. 准备工作
   ├─ 剧本内容物清点清单（剧本/结局/图/卡，逐类计数）★
   ├─ 前期准备物品与打印物品（一次性道具每场必印清单）
   └─ 音频清单（分幕 BGM 曲名+切换时机）★
3. 开场流程：开场话术（时代氛围独白）→ 角色介绍话术 → 选角机制（党史/校史答题定选角顺序）→ 阅读指令话术
4. 分幕流程（每幕统一小节）：
   ├─ 胜利条件/结算规则讲解话术
   ├─ 环节规则讲解话术（放慢语速强调关键规则×3：如"卡牌与房间绑定/不可重复抽取/支线触发时段"）★
   ├─ 分环节流程：背景话术→规则→进行（含 DM 控场注意、道具准备）→结算话术→过渡话术
   ├─ 扶车话术库 ★：
   │   ├─ 控时提醒（"讨论时间即将结束，请尽快分享关键信息"）
   │   ├─ 偏题引导（"大家可以先结合NPC的可疑原因，分享手中的线索"）
   │   ├─ 分级提示（先模糊提示→再缩小范围→最后明牌，如密码"注意画面左上方"）
   │   ├─ 保真相纪律（"DM需牢记此真相，不提前泄露"；核心暗示线索确保被搜出）
   │   └─ 兜底机制（"校车接送""看五分钟广告复活"式防卡死设计）
   ├─ 支线任务执行细则（触发条件→私下告知内容→执行流程→奖励→绑定规则示例）
   └─ 结算环节：答题/主线/支线/总分逐项公布话术 + 登记表要求
5. 结局与演绎：结局触发条件矩阵（按阵营投票/隐藏指认组合）→ 每结局一段演绎话术
   （常用"报纸头版社论"或"灯光暗下+真相独白"两种文体）★
6. 奖励结算与道具回收流程
7. DM 速查表：角色-技能-任务对照表、NPC-线索对照表、人员分工表
   （实景本需 4 人分工：主控/记录/演绎A/演绎B，含每人时间线）★
8. 史实边界标注（必备节）★：
   ├─ 用独立小节或红字标注哪些是真实史实（时间/人物/口号/精神），哪些是虚构演绎
   ├─ 对"真/假线索"（如真账本/假账本）明确标注道具的真实归属，DM 知道但不可泄露
   ├─ 虚构情节不得与已锚定史实冲突；价值导向话术（精神口号背诵、升华独白）单独标注
   └─ 敏感时代背景的处理口径：敌人设定为"青年巡查队"等模糊群体，避免影射
```

## 四、各类卡牌文案骨架

| 卡牌类型 | 骨架 | 备注 |
|---|---|---|
| 线索卡 | 编号【JX-1】+ 地点 + 一句物证描述（客观、可推理、不含结论）+ 真假标记（DM 侧）★ | 真假约 2~3 真 : 1~2 假/搜证分区 |
| 问题卡 | 题目（历史/校史知识）+ 答案 + 分值（如答对+20票）+ 空白卡版本 | 空白卡占多数，控制成本 |
| 特殊卡 | 触发条件 + 效果 + 使用限制 | 动作牌：盘查/呼应/问责/转移等 |
| 紧急任务卡 | 保密提示（"请立即与DM私下沟通"）+ 阵营支线开启说明 | 阵营支线触发器 |
| 支线任务卡 | 任务目标 + 执行流程（a/b 步）+ 奖励 + 绑定规则 | 与搜证房间线索卡一对一绑定 |
| 道具卡 | 名称 + 效果（资源数值或免疫/跳过类）+ "贯通全本，限用X次" | 信物类贯通全本 |
| 事件卡 | 【沉浸话术】+【事件效果】+【触发动作】三段式 ★ | 棋盘格/情境推进用 |
| 校史/史实碎片卡 | 时间+事件碎片句；集齐≥2可猜完整信息换分 | 前置资料发放 |
| 成就卡/贴纸 | 编号+四字名称 + 达成条件 + 一句话颁奖词 ★ | 命名+文案即物料 |
| 小道消息卡 | 一句传闻（真/迷惑混合）+ 售价+限购+特定角色可见标记 | 付费信息通道 |
| 投票纸 | 必填项（指认对象）+ 选填项（背后指使/理由）+ 匿名提交说明 | 多结局触发依据 |

## 五、标准物料清单（生成剧本时同步输出）

**A. 文本打印类**
- DM 手册（含全部话术/速查表/道具表）、人物剧本×6、结局文本（主线结局数=触发矩阵行数）、题目汇总、打印数量统计表（标注纸张/单双面/彩色/尺寸/一次性）★

**B. 卡牌类（硬卡纸 70×100mm 双面彩印为基准）**
- 线索卡、问题卡、特殊卡/事件卡、道具卡、支线/紧急任务卡、投票纸、成就贴纸、小道消息卡；每类给出数量、卡面卡背配色对应规则

**C. 道具类**
- 货币道具（标注面值与印刷数量）、信物（每人1~2件）、搜证容器（密码箱/档案箱，真假道具成对设计）、地图/平面图（A3 及以上）、记分白板/统计表、签字笔+白纸按人数配

**D. 氛围类**
- 分幕 BGM 清单与切换时机、警报/紧张音效、NPC 服化与点位表（实景本）、场景平面图（点位照片存档要求）★

**E. 人员类**
- DM 人数与分工表（主控/物资登记/题目辅助/NPC 演绎）、NPC 候场与埋伏时间线

---

### 生成自检清单（生成后逐项核对）
1. 玩家本每页有翻页限制行；秘密信息仅出现在持有者本中
2. 三幕资源是否贯通、是否有兜底机制防玩家卡死
3. DM 本是否含：分环节时长、控时/扶车话术、真相保密纪律、结局触发矩阵、史实边界标注
4. 卡牌是否覆盖：线索（含真假）/任务/道具/投票/成就 五类
5. 物料清单是否可直接转为打印统计表（数量/尺寸/材质/一次性标注齐全）
6. 价值导向是否有点题设计（口号/社论/独白式升华话术）
