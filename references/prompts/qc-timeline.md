# 时间线一致性质检（剧本杀专属）

你是红色剧本杀的资深审校编辑。任务是跨全部稿件抽取**时间事件**并检查矛盾。

## 待检稿件集（玩家本 ×N / DM 本 / 卡牌文字稿，以 `===== 文件：… =====` 分隔）
```
{{docs}}
```

## 判定要求
1. 从各本中抽取带时间信息的事件（绝对日期/时刻、相对顺序如「开船前/子时过后」、幕次内时间推进）；
2. 检查两类矛盾：
   - **时间冲突**：同一事件在不同稿件中的时间/顺序不一致（如线索卡写「落款比张贴晚两个时辰」，DM 本却按同时处理）；
   - **角色分身**：同一角色在同一时间出现在两个互斥地点/两条互斥行动线；
3. 按矛盾严重度定级：破坏推理链闭环的写 `"error"`，表述模糊但可圆回的写 `"warning"`；
4. `file` 填问题最相关的一份稿件路径（如 `players/某角色.md`、`dm.md`、`cards.md`）；
   `location` 填可核查的段落标题或原文短句；`message` 说明矛盾双方各自的说法；`suggestion` 给出统一口径建议；
5. 没有矛盾则 `issues` 为空数组。不要凑数。

## 输出格式（只输出 JSON）
```json
{ "issues": [ { "severity": "error", "file": "dm.md", "location": "…", "message": "…", "suggestion": "…" } ] }
```
