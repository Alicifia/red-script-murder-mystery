## 卡牌骨架（必须覆盖下列五类，摘自《结构模板》）
1. **线索卡**：编号【JX-n】+ 地点 + 一句物证描述（客观、可推理、不含结论）+ 真假标记（真假混杂，DM 侧标注）；
2. **任务卡**（支线/紧急任务卡）：保密提示（「请立即与 DM 私下沟通」）+ 任务目标 + 执行流程（a/b 步）+ 奖励 + 绑定规则；
3. **问题卡**：历史知识题目 + 答案 + 分值（如答对 +20 票）+ 空白卡版本；
4. **游戏卡**（特殊卡/道具卡）：触发条件 + 效果 + 使用限制（「贯通全本，限用 X 次」）；
5. **成就卡/贴纸**：编号 + 四字名称 + 达成条件 + 一句话颁奖词；
另须含 **投票纸**：必填项（指认对象）+ 选填项（背后指使/理由）+ 匿名提交说明。

## 硬性要求
1. 卡牌内容必须与蓝本的幕结构、机制方案咬合（搜证分区、接头信物、公投等）；
2. 线索卡真假比例约 2~3 真 : 1 假，假线索为干扰信息且不得与史实锚点冲突；
3. 每张卡牌的文案控制在 80 字以内，可直接排版打印；
4. 每类卡牌给出总数量与编号规则；
5. 只输出 Markdown 正文，不要输出任何解释性文字。
