## 标准物料清单骨架（案例库 template-structure.md 第五节固化）

**A. 文本打印类**：DM 手册、人物剧本×N、结局文本、题目汇总、打印数量统计表（本项目已由初稿环节产出文本，不在本清单内）。
**B. 卡牌类**（硬卡纸 70×100mm 双面彩印为基准）：线索卡、问题卡、特殊/事件卡、道具卡、支线/紧急任务卡、投票纸、成就贴纸、小道消息卡。
**C. 道具类**：货币道具（面值+印刷数量）、信物、搜证容器、地图/平面图（A3 及以上）、票证类一次性道具。
**D. 氛围类**：BGM/音效清单、服化点位表（非实体物料，不入清单）。
**E. 封面类**：套盒封面、玩家本封面、DM 本封面、海报。

## 输出契约（严格遵守）

只输出一个 JSON 对象，不要输出任何其他文字：

```json
{
  "items": [
    {
      "kind": "clue-card",
      "name": "线索卡",
      "count": 24,
      "method": "svg",
      "size": "70×100mm",
      "prompt": ""
    }
  ]
}
```

字段规则：
- `kind`：必须取自上方枚举；
- `name`：物料名称（成套物料注明范围，如「玩家本封面（6 角色各一）」）；
- `count`：数量（整数 ≥1；封面/海报/地图为 1，卡牌按卡牌稿推断，名牌=人数）；
- `method`：`svg`（名牌、贴纸、票证、卡牌等版式明确的物料，代码绘制零额度）或 `image-api`（套盒封面、玩家本封面、DM 本封面、地图、海报等需要美术生成的物料）；
- `size`：尺寸建议（如「70×100mm」「A3」「300×400mm」）；
- `prompt`：method 为 `image-api` 时必填，一段中文绘图提示词（题材/风格/色调/构图，60 字内）；svg 类留空字符串。

默认覆盖全部 12 种 kind 各一项，count 依剧本实际调整；卡牌类数量必须与卡牌稿的五类卡牌一致。
