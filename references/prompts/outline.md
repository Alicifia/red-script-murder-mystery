## 硬性要求
1. 三幕结构：第一幕机制热身+攒资源、第二幕核心推理、第三幕搜证+终局谈判/投票；跨幕资源（货币/积分/羁绊）必须贯通；
2. 至少一条对抗线（阵营对抗 / 隐藏身份对抗 / 个人任务对抗）；
3. 全程约 3.5-4.5 小时，大纲中给出每幕的建议时长；
4. 「史实锚点 + 虚构案件」双层结构：真实历史做背景锚点，虚构案件承载玩法；
5. 角色设置：列出 {{playerCount}} 个角色（姓名、明面身份、一句话暗线定位），明线/暗线/摇摆位搭配；
6. 大纲最后一节固定为「史实与虚构边界」：逐条列出哪些是史实（须能以知识库条目佐证）、哪些是艺术虚构；
7. 只输出 Markdown 大纲正文，不要输出任何解释性文字。
