```
0. 排版规范说明（保留本节）：
   黄色背景=需播放的音频；黑字=基本框架；红字=DM 注意事项；
   蓝字=DM 需要说的话；绿色=时间节点标记；加粗=需重读/特别注意
1. 类型介绍：人数、阵营构成、角色定位一览表、难度与 DM 经验要求（「切勿盲开」提示）
2. 准备工作：剧本内容物清点清单（逐类计数）/ 前期准备与打印物品（一次性道具每场必印清单）/ 音频清单（分幕 BGM+切换时机）
3. 开场流程：开场话术（时代氛围独白）→ 角色介绍话术 → 选角机制（党史/历史答题定选角顺序）→ 阅读指令话术
4. 分幕流程（每幕统一小节）：
   - 胜利条件/结算规则讲解话术
   - 环节规则讲解话术（关键规则放慢语速强调 ×3）
   - 分环节流程：背景话术→规则→进行（含 DM 控场注意、道具准备）→结算话术→过渡话术
   - 扶车话术库：控时提醒 / 偏题引导 / 分级提示（先模糊→再缩小范围→最后明牌）/ 保真相纪律 / 兜底机制（防卡死）
   - 支线任务执行细则（触发条件→私下告知内容→执行流程→奖励→绑定规则）
   - 结算环节：逐项公布话术 + 登记表要求
   - 每环节标注建议时长并配控时提醒话术
5. 结局与演绎：结局触发条件矩阵（按投票/指认组合）→ 每结局一段演绎话术
6. 奖励结算与道具回收流程
7. DM 速查表：角色-技能-任务对照表、NPC-线索对照表、人员分工表
8. 史实边界标注（必备节）：
   - 独立小节标注哪些是真实史实（时间/人物/口号/精神，须注明可佐证的来源类型）、哪些是虚构演绎
   - 真/假线索道具的真实归属（DM 知道但不可泄露）
   - 虚构情节不得与已锚定史实冲突；价值导向话术（口号背诵、升华独白）单独标注
   - 敏感时代背景处理口径：对手设定为模糊群体，避免影射
```
