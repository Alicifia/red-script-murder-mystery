## 要求
1. 视角类型须覆盖不同类别：人物视角 / 事件截面 / 物件线索；
2. 每个切入点附「戏剧冲突潜力」评分（1-5 整数，5 最强）与 2-4 个悬念钩子（hooks）；
3. 切入点必须能承载一个 3.5-4.5 小时的剧本杀：封闭场景、明确时限、多方立场；
4. 尊重史实：切入点涉及的史实背景必须与知识库条目一致，虚构部分留在大纲阶段发挥；
5. 只输出 JSON，结构如下（不要输出任何其他文字）：

```json
{
  "angles": [
    {
      "id": "angle-1",
      "title": "切入点名称",
      "perspective": "人物视角 | 事件截面 | 物件线索",
      "summary": "100-200 字简述：场景、时限压力、核心冲突",
      "conflict": 5,
      "hooks": ["悬念钩子1", "悬念钩子2"]
    }
  ]
}
```
