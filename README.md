从红色历史题材到可开团的完整剧本杀成品（玩家本 / DM 本 / 卡牌 / 物料）的 15 步 AI 创作工作流，打包为 Kimi / Claude Code 等 Agent 通用的 Skill。

## 它能做什么

给一个红色历史题材（党史、工运、校史、抗战……），Agent 会引导你走完：

1. 检索词扩写 + 广域搜索（小众事件优先命中地方志/党史网/校史馆）
2. 知识库提取去重 → 史实锚点
3. 切入点候选 → 三幕大纲 → 多方案机制 → 创作蓝本（含角色信息边界表）
4. 玩家本 ×N（视角限定）→ DM 手册（8 节）→ 五类卡牌文字稿
5. 史实边界 / 视角泄漏 / 时间线 三件套质检 + 定点修复循环
6. 物料清单 → 封面海报绘制（Agent 支持绘图则直接代绘，否则输出提示词清单给你拿去外部绘图 AI）→ 分类打包 → 案例提炼

## 安装

- **Kimi Work / Kimi Code**：把本仓库的 `red-script-murder-mystery/` 文件夹复制到技能目录（如 `~/.kimi/skills/` 或 daimon 的 skills 根目录）。
- **Claude Code**：放入 `.claude/skills/` 或 `~/.claude/skills/`。
- 也可以直接下载 releases 中的 `.skill` 分发包安装。

安装后新开对话，说一句「用××事件做一个剧本杀」即可触发。

## 目录结构

```
red-script-murder-mystery/
├── SKILL.md                    # 工作流主文件（15 步流程 + 决策点 + 铁律）
└── references/
    ├── structure-template.md   # 玩家本/DM本/卡牌/物料标准骨架（含自检清单）
    ├── cases-template.md       # 自建案例库条目模板（本仓库不附真实案例）
    └── prompts/                # 14 个阶段提示词（含占位符，原样可用）
```
